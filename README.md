# Hotel Revenue Analytics (Power BI)
## About the Project
This project focuses on analyzing hotel data to understand how revenue is generated and what factors influence it. A Power BI dashboard is used to visualize patterns such as bookings, revenue trends, and customer behavior.
## Work Done
* Used hotel dataset from Excel
* Cleaned and prepared the data
* Built an interactive dashboard in Power BI
* Used different charts to represent the data clearly
## Tools Used
* Power BI : For Dashboard
* Microsoft Excel : For Data
## What the Dashboard Shows
* Revenue changes over time
* Booking trends (daily/monthly)
* Customer-related insights
* Comparison of performance
## Files Included
* Power BI dashboard file (.pbix)
* Dataset (.xlsx)
* Project report (.pdf)
## Learning Outcome
This project helped in understanding how data visualization supports better decision-making. It also provided experience in working with real-world data and presenting it effectively using Power BI.
## Conclusion
The project shows how data analytics can be applied in the hotel industry to improve revenue analysis and planning.
## Note
The .pbix file can be opened in Power BI Desktop to explore the dashboard.
